## 1. 通用说明

| 项目 | 内容 |
|------|------|
| 基础URL | `/api/v1` |
| 认证 | 暂不启用（后续可加 token） |
| 返回格式 | `application/json` |
| 时间格式 | `YYYY-MM-DDTHH:mm:ssZ` (UTC/ISO8601) |
| 分页参数 | `page`（默认1）, `pageSize`（默认20） |
| 成功 code | 0 |
| WebSocket 日志端点 | `/ws/sim/log/{runId}` |

通用响应：
```
{
  "code": 0,
  "message": "success",
  "data": {...}
}
```

错误响应示例：
```
{
  "code": 40009,
  "message": "端口冲突",
  "data": null
}
```

## 2. 项目管理

### 2.1 项目列表查询

#### 基本信息
> 请求路径：`/projects`  
> 请求方式：GET  
> 描述：分页查询项目信息  

#### 请求参数（query）
| 参数名    | 类型    | 是否必须 | 示例             | 说明              |
|-----------|---------|----------|------------------|-------------------|
| page      | number  | 否       | 1                | 页码，默认 1      |
| pageSize  | number  | 否       | 20               | 每页数量，默认 20 |
| keywords  | string  | 否       | Modbus           | 按名称/描述模糊查询 |

#### 响应参数
| 参数名              | 类型      | 说明                    |
|---------------------|-----------|-------------------------|
| code                | number    | 0 成功                 |
| message             | string    | 提示信息（可为空）      |
| data.list[].projectCode | string | 项目标识              |
| data.list[].projectName | string | 项目名称              |
| data.list[].simTimeLimit | string | 默认仿真时长         |
| data.list[].status  | number    | 0未运行 1运行中 2完成 3失败 |
| data.list[].createTime | string | 创建时间              |
| data.total          | number    | 总记录数                |

#### 响应样例
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "projectId": 1,
        "projectName": "测试项目A",
        "simTimeLimit": "10s",
        "status": 0,
        "createTime": "2025-11-10T07:50:00Z"
      }
    ],
    "total": 1
  }
}
```

## 10. 仿真结果查询与导出

### 10.1 结果分页查询

> 请求路径：`/simulation-results`  
> 请求方式：GET  

#### 请求参数
| 名称       | 类型   | 必须 | 示例            | 说明                    |
|------------|--------|----|----------------|-------------------------|
| projectName| string | 否 | 工业控制仿真实验1 | 仿真实例标识           |
| metricType | string | 否 | scalar           | scalar/vector    |
| metricName | string | 否 | delay            | 指标名/模块模糊匹配     |
| page       | number | 否 | 1                | 页码                    |
| pageSize   | number | 否 | 50               | 每页记录数              |

#### 请求样例
```json
`/simulation-results?projectName="工业控制仿真实验1"&metricType="scalar"&metricName="delay"&page=1&pageSize=50
```

#### 响应样例
```json
{
  "code":0,
  "data":{
    "list":[
      {"metricName":"endToEndDelay","metricType":"scalar","sourceModule":"client[0].app[0]","value":0.0023}
    ],
    "total":12
  }
}
```

## 11. 向量数据分块 & 聚合统计

### 11.1 聚合统计

> 请求路径：`/simulation-results/aggregate`  
> 请求方式：GET  

#### 请求参数
| 名称        | 类型   | 必须 | 示例                            | 说明                         |
|-------------|--------|------|---------------------------------|------------------------------|
| projectId       | number | 是   | 1               | 仿真项目                    |
| metrics     | string | 是   | endToEndDelay,throughput        | 逗号分隔多个指标名           |
| percentiles | string | 否   | 95,99                           | 需要的分位（可为空）         |

#### 响应样例
```json
{
  "code":0,
  "data":{
    "endToEndDelay":{"min":0.0012,"max":0.0067,"avg":0.0029,"p95":0.0058,"p99":0.0065},
    "throughput":{"min":1234,"max":5678,"avg":3456}
  }
}
```

## 17. 错误码表

| code  | message | 说明                                 |
|-------|---------|--------------------------------------|
| 40001 | 项目名已存在 | 创建项目冲突                      |
| 40002 | 节点类型不支持 | nodeType 非法                   |
| 40003 | 拓扑缺少必需节点 | 缺少 server/client 等           |
| 40004 | 启动参数缺失 | simTimeLimit 等缺失              |
| 40005 | 仿真运行中禁止重复启动 | 防止重复提交             |
| 40006 | HIL 客户端配置缺失 | remoteAddress/remotePort 缺失 |
| 40007 | MasterConfig 内容非法 | 结构校验失败             |
| 40008 | SlaveConfig 内容非法 | 结构校验失败             |
| 40009 | 端口冲突 | 同节点 localPort 重复               |
| 40010 | 无有效客户端 | 拓扑中无 Client                  |
| 40401 | 项目不存在 | projectCode 无效                  |
| 40402 | 节点不存在 | nodeId 不存在                     |
| 40403 | 拓扑版本/文件不存在 | version 无效 / 文件缺失    |
| 40404 | 仿真实例不存在 | runId 无效                      |
| 50001 | 脚本执行失败 | run_sim.sh 异常                  |
| 50002 | SQLite 解析异常 | 结果解析失败                  |
| 50003 | INI 生成失败 | 模板或数据错误                   |
| 50004 | NED 生成失败 | 拓扑转换错误                     |
